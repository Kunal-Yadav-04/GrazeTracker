
GrazeTracker 🖱️👁️

Head & Eye Movement Controlled Cursor using Python, OpenCV, Raspberry Pi & IR Sensors

GrazeTracker is an assistive computer-control system that allows users to control a computer cursor without using a traditional mouse.

The project combines computer vision and hardware sensors to translate head and eye movements into cursor navigation, while IR sensors are used for intentional mouse-click input.

🚀 Features

* Control the cursor using head and eye movements
* Real-time movement detection using OpenCV
* IR sensors for mouse-click interaction
* Runs on Raspberry Pi
* Enables hands-free computer interaction
* Designed as an exploration of low-cost assistive technology

💡 Why I Built It

I wanted to explore whether computer vision and low-cost hardware could be combined to create a practical alternative to traditional mouse interaction.

Instead of relying completely on computer vision for every input, I decided to use a hybrid approach. OpenCV handles cursor movement, while IR sensors are used for clicking. This makes the interaction more reliable and helps reduce accidental clicks.
